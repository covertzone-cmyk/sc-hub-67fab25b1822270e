# How to point other AIs at this folder

How Suzanne points Claude, ChatGPT, and other AIs at this folder.

- Repo: https://github.com/covertzone-cmyk/sc-hub-67fab25b1822270e
- Folder: `/shared`

If the repo is private, Claude and ChatGPT cannot see GitHub until she either connects GitHub or copies these files into a Project.

## Claude

Open a Project (or a new chat). Add the files in `shared/` as project knowledge, or connect GitHub and point at this repo. Paste the instruction below.

## ChatGPT

Open a Project or Custom GPT. Upload the `shared/` markdown files, or connect GitHub if available. Paste the same instruction.

## Instruction to paste

This GitHub folder is the source of truth for Suzanne Covert Photography: https://github.com/covertzone-cmyk/sc-hub-67fab25b1822270e/tree/main/shared

Always read `shared/business.md`, `shared/proposals.md`, and `shared/email-voice.md` before you draft a proposal, quote, or client email. Read `shared/open-work.md` before you touch a live client thread. Write durable updates back into those files. Do not invent rates. Ask for the dollar number on any group or on-site job. Never send email. Never use em dashes.
